# TrackLine Circuit Globe

An interactive 3D globe with the 12 circuits in the TrackLine tee collection. Click a pin (or a name in the list) to fly to the circuit
and open a card with a "Shop the tee" link to `https://tracklinewear.com/products/<handle>` (opens in the top window, so it works when embedded in an iframe).

## Run it

No build step. Serve the folder with any static server and open `index.html`:

```sh
python3 -m http.server 8000
```

All libraries (three.js, d3-geo, topojson-client) and the Natural Earth country map are in `vendor/`, so it works offline.

## Editing circuits

Edit `tracks.js`: each row is `[name, country, lat, lon, shopHandle, note]`.

## Close-up circuit maps

Selecting a circuit flies down to it and draws a close-up from OpenStreetMap data: the circuit as a glowing white line
that draws itself, over the nearby roads, water, forest and buildings. The overlay fades out as you zoom back out.

The data lives in `data/tracks/<handle>.geojson` and is generated by:

```sh
python3 scripts/fetch_osm.py            # all tracks
python3 scripts/fetch_osm.py monza-t-shirt   # one track
```

It queries the Overpass API (trying several mirrors), finds the circuit (an OSM `type=circuit` relation, or else
`highway=raceway` ways) and everything within ~2.5 km, and writes simplified GeoJSON. Raw responses are cached in
`scripts/.cache/`. Per-track hints are in `TRACK_OPTS` at the top of the script: several circuits (Isle of Man, Le Mans, Long Beach,
Nordschleife) are mapped as route relations rather than `type=circuit`, so their relation ids are pinned there.
The Nürburgring (24h layout: Nordschleife + GP section) and the Silverstone kart track use a `loop` override: the exact
lap as ordered OSM way ids, chosen to match the TrackLine shirt print.
